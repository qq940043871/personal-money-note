# 首页门户 (home.html)

## 页面概述
投资交易系统的默认首页，展示用户投资概览、市场动态、投资组合和最新学习心得等关键信息。

## 功能需求
1. 数据概览卡片
   - 总资产、今日收益、学习笔记、政策更新四项关键指标
   - 带趋势箭头的变化提示
2. 市场动态面板
   - 上证指数、深证成指、创业板指、沪深300实时行情
3. 投资组合概览
   - 持仓股票列表（贵州茅台、宁德时代、隆基绿能、比亚迪）
4. 最新学习心得
   - 按时间倒序展示最近三条学习笔记
5. 最新经济政策
   - 展示最近三条政策更新

## 页面结构
- 页面标题栏（标题 + 描述）
- 四列统计卡片网格
- 双列布局：市场动态 + 投资组合
- 双列布局：学习心得 + 经济政策

## 技术实现
- Tailwind CSS 响应式网格布局
- Font Awesome 图标
- 静态模拟数据
- 通过 `parent.loadPage()` 实现 iframe 内导航
