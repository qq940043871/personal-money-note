# 散户误区 (retail_mistakes/index.html)

## 页面概述
散户投资者常见误区汇总，分类展示心理误区和行为误区，并提供应对策略。

## 功能需求
1. 误区概览统计
   - 常见误区数量、已学习数量、收益提升预估
2. 心理误区分类
   - 过度自信、损失厌恶、羊群效应
3. 行为误区分类
   - 追涨杀跌、锚定效应、处置效应
4. 重点误区详解
   - 过度交易、情绪化投资的详细分析
5. 学习进度跟踪
   - 进度条展示掌握程度

## 页面结构
- 统计卡片行
- 双列误区分类
- 重点误区详解区域
- 学习进度区域

## 技术实现
- 点击跳转到详情页 `parent.loadPage('trading/retail_mistakes/overtrading.html')`
- 进度条组件
